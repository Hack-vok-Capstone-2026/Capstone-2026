The capstone project

Finding signals worth a closer look

The Kepler catalog contains thousands of objects of interest. Turning that catalog into a useful research shortlist takes careful data preparation, fair model evaluation, and a separate review of false positive indicators. This application brings those steps together so anyone can explore the team’s results.

01 / Problem

A large, complex catalog

The supplied Kepler dataset has 9,564 records with missing values, outliers, repeated host stars, and many technical measurements. Raw rows are difficult to compare or browse.

What we solved

We prepared a 60-column analysis dataset, documented missing-value decisions and outliers, and built a searchable catalog with readable object details.

02 / Problem

Which candidates deserve attention?

A catalog label alone does not rank candidate objects for follow-up. Comparing models can also be misleading if observations from the same host star appear in both train and test sets.

What we solved

We split data by host star, compared Logistic Regression with Random Forest, and ranked 438 candidates using the team’s saved predictions. The supplied validation report records zero host stars shared across the split.

03 / Problem

Promising signals can mislead

Stellar eclipses, contamination, unusual transit depths, and extreme measurements can resemble planetary signals. A high model probability does not establish a discovery.

What we solved

We added a transparent screening layer with evidence for human review. Among 438 ranked candidates, 30 are marked high risk, 34 medium risk, and 374 low risk by the supplied screening rules.

How the workflow connects

From catalog data to a reviewable shortlist

1PrepareClean the catalog, classify columns, review missing values, flag outliers.
2EvaluateSeparate host stars across train and test, compare classification models.
3PrioritizeRank candidate records by the saved model probability and priority.
4ReviewInspect catalog flags, screening evidence, and individual object measurements.
